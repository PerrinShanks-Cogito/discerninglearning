# Word documents

Upload a `.docx` here and GitHub converts it to a web page automatically.

- `word/` — becomes a **blog post** in `_posts/`.
- `word/pages/` — becomes a **page** in `_pages/` (URL `/<file-name>/`).

Start the file name with a date (`2025-07-04 My post.docx`) to set the post
date; otherwise it is dated the day it is first converted. See the main
README for details.
