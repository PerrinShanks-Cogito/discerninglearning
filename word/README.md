# Word documents

Upload a `.docx` into one of these folders and GitHub converts it to a web
page automatically:

- `midlife-musings/` — a **blog post** (Midlife Musings), in `_posts/`.
- `my-approach/` — a **My Approach** entry, in `_my_approach/`.
- `data-work/` — a **Data Work** entry, in `_data_work/`.
- `pages/` — a stand-alone **page**, in `_pages/` (URL `/<file-name>/`).

Documents put straight into `word/` are not converted.

Start the file name with a date (`2025-07-04 My post.docx`) to set the post
or entry date; otherwise it is dated the day it is first converted. See the
main README for details.
